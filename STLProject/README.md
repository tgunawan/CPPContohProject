# STLProject

Contoh project C++ yang menggunakan `std::set`, `std::map`, dan algoritma STL.

## Struktur
- `main.cpp` - contoh penggunaan `set`, `map`, `find_if`, `sort`, dan loop.

## Build
Gunakan perintah berikut di folder `STLProject`:

```powershell
cd c:\Users\Tedi Gunawan\MyDocuments\c++\STLProject
g++.exe -std=c++17 main.cpp -o STLProject.exe
.\STLProject.exe
```
